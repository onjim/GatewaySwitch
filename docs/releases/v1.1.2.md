# v1.1.2 - 原生路由 API 重构与路由守护稳定性增强

## 主要改进

- **原生 Win32 路由操作**：新增 [NativeNetwork.cs](../../NativeNetwork.cs)，使用 `iphlpapi.dll`（`GetIpForwardTable2`、`CreateIpForwardEntry2`、`SetIpForwardEntry2`、`DeleteIpForwardEntry2`）直接读写系统活动路由表，彻底移除对 `powershell.exe` 和 `NetTCPIP` 模块的依赖，避免精简系统缺失模块、杀软拦截或 20 秒超时问题，操作耗时降至毫秒级。
- **原生 DNS 配置与缓存刷新**：使用 `netsh.exe` 与 `dnsapi.dll`（`DnsFlushResolverCache`）配置并刷新 DNS，并通过 `NetworkInterface` 原生读取当前生效 DNS 完成校验。
- **按 Metric 过滤路由冲突**：修复检测与启用校验时，忽略优先级低于目标路由（如路由器周期性 RA 广播下发的 `RouteMetric = 4096` IPv6 默认路由）的背景路由，仅处理同级或更高优先级（`RouteMetric <= 目标 Metric`）的竞争默认路由，消除频繁无效修复及校验竞态报错。

## 兼容性与健壮性

- **IPv6 自适应降级**：若目标网卡未启用 IPv6 协议栈，自动跳过 IPv6 旁路由路由及 DNS 配置并写入日志，不阻断 IPv4 旁路由正常启用。
- **虚拟 / TUN 网卡过滤增强**：补充识别并过滤 `wintun`、`wireguard`、`tap-`、`tun `、`tailscale`、`clash`、`mihomo`、`zerotier`、`sing-box`、`nekoray`、`utun` 等虚拟适配器。
- **受限环境容错与全量错误日志**：`CommandJob` 不可用时自动降级监控进程；启用、恢复与路由修复的异常堆栈统一记录至 `%LOCALAPPDATA%\GatewaySwitch\gateway.log`。
- **兼容旧版备份格式**：继续支持解析旧版本保存的 `RoutesJson` 备份数据，平滑升级恢复。
